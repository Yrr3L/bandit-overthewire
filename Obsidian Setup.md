# Program for Task
## Install Obsidian
Download and install [Obsidian](https://obsidian.md/download)
## Create Vault
1. Open Obsidian
2. Click Create Vault
3. Input Vault Name - Notes
## Create Folder and Templates

| Folder   | Sub Folder  |             Template |
| :------- | :---------: | -------------------: |
| Journals | Daily Notes |                      |
| Template |             | Daily Note Templates |
| Task     |             |                      |
## Access Assets
Download [Assets](https://drive.google.com/drive/folders/16cX-Lm0o7juPkeYZ2GHXP-AvF5jvvCyE)
## Add Asset
1. Open Obsidian - Choose a folder, then right click choose show in system explorer - then that folder will show Windows Explorer
2. Adding Asset Folder Task and Templates
	1. Open Asset folder from Assets Download before
	2. Choose  Asset Folder Task and Templates copy to  init Vault
3. Add Folder Multi Column
	1. Open Setting on Obsidian -> Apperance CSS snippet 
	2. Copy Multi Column CSS to .obsidian on vault root
## Install Community Plugin

| Plugin        | Function                   | Set   |
| ------------- | -------------------------- | ----- |
| Journals      | Write Journal - daily nota | Yes   |
| Dataview      | Show Data                  | Yes   |
| Templater     | Program for Template       | Yes   |
| Task          | Manage Task                | Tidak |
| Style Setting | Enable CSS Snippet         | Tidak |
